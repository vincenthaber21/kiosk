About these products

The palay desk uses two fixed products: Rice Palay (unmilled rice bought from farmers or sold from stock) and Bigas (milled rice). Edit each card to set default buy/sell prices, adjust opening stock, configure low-stock alerts, and set per-ticket quantity limits. New trades pull rates from these features automatically.
